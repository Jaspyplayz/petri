# Petri

> *Project name is a placeholder.*

Petri is a self-evolving web app: users submit feedback, and AI agents turn that feedback into feature proposals, build them, verify them against CI and guardrails, and auto-merge them — all without a human in the loop. Every change is recorded on a public timeline, so anyone can watch the app grow and mutate in real time, like a culture in a petri dish.
