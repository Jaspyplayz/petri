- 2026-10-22 · P1 · TypeScript pinned to 6.0.3, not 7.x — typescript-eslint (Phase 2 strict-type-checked) supports `<6.1.0` only.
- 2026-10-22 · P1 · Turned on the Phase 2 strict TS flags (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, …) from the start — cheaper than retrofitting; Phase 2 adds the bans and CI.
- 2026-10-22 · P1 · Keep Next 16's defaults `cacheComponents` + `partialPrefetching`; all DB reads sit inside `<Suspense>` so pages are a static shell plus streamed fresh data.

- 2026-10-22 · P1 · No `@supabase/ssr`: there is no auth, so plain `supabase-js` with `persistSession: false` is enough (anon client for reads, `server-only` service client for writes).
- 2026-10-22 · P1 · Rate limiting is one atomic Postgres function `consume_rate_limit` (advisory lock per hash+action, prunes old rows) callable only by service_role — race-free and one round trip.
- 2026-10-22 · P1 · Anon gets no default privileges in `public` (`alter default privileges … revoke`), so a future table is never exposed by accident; every grant is explicit and column-level for `feedback`.
- 2026-10-22 · P1 · Repeat votes are idempotent (200 `{alreadyVoted:true}`) instead of 409 — Chrome logs 4xx fetches as console errors, which the e2e fixture rightly fails on, and a repeat vote isn't an error for the visitor.
- 2026-10-22 · P1 · Client IP = first `x-forwarded-for` entry (Vercel overwrites it). Locally it's client-controlled; the shared e2e fixture sends a random one per test so rate-limit buckets don't collide across tests and reruns.
- 2026-10-22 · P1 · Feature-to-feature contracts live in `shared/`: `shared/lib/track.ts` (analytics) lets blob/feedback send events without importing the analytics feature. Pages compose `PageView` from `features/analytics`.
- 2026-10-22 · P1 · No `useEffect` in features: the blob uses `useSyncExternalStore` (`shared/lib/use-local-storage.ts`); the only effects live in `shared/ui/effects/` (`useMountEffect`, `useReportError`) — the Phase 2 allow-list.
- 2026-10-22 · P1 · Unit tests run in Node (no jsdom): all logic worth unit-testing is pure and lives in `lib/`; UI behaviour is covered by Playwright e2e against `next build && next start`.
- 2026-10-22 · P1 · `src/features/registry.ts` is regenerated by `pnpm new:feature` and is the single list of manifests for scripts (feature map, verify) — no folder globbing at runtime.
- 2026-10-22 · P1 · No Google Fonts (system rounded font stack) — builds and e2e don't need network access.
- 2026-10-22 · P1 · Sentry is set up by hand (no wizard): `enabled` only when `NEXT_PUBLIC_SENTRY_DSN` is set, release = `VERCEL_GIT_COMMIT_SHA ?? GITHUB_SHA`, source maps uploaded only when token/org/project exist. `sendDefaultPii` was removed in SDK v11 (no PII is the default).
